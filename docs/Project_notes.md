# Salary Management System – Project Notes

## Objective

Build a minimal salary management system for HR managers handling 10,000 employees.

The system supports:

* Employee CRUD operations
* Salary insights
* Salary analytics by country and job title

---

# Tech Stack

Frontend:

* React.js
* React Router
* Axios

Backend:

* Node.js
* Express.js
* Prisma ORM

Database:

* PostgreSQL

---

# Core Features

## Employee Management

* Add employees
* View employees
* Update employees
* Delete employees

## Salary Insights

* Minimum salary
* Maximum salary
* Average salary
* Salary insights by country
* Salary insights by job title

---

# Product Thinking

The application is designed for HR managers.

Focus areas:

* Simple employee management
* Fast salary visibility
* Easy analytics
* Scalable backend structure
