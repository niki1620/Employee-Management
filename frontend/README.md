# Frontend - Salary Management System

This is the frontend application for the Salary Management System built using React and Vite.

## Tech Stack

* React.js
* React Router
* Axios
* Vite

## Features

* Employee management interface
* Salary insights dashboard
* CRUD operations
* Responsive UI
* API integration with backend

## Setup

```bash
npm install
npm run dev
```

## Environment Variables

Create a `.env` file:

```env
VITE_API_URL=your_backend_url
```

## Build

```bash
npm run build
```
